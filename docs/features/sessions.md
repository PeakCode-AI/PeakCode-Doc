# 会话持久化

Peak Code 的会话在应用重启后依然保留，让你随时回到之前的工作。

---

## 智能检查点

| 机制 | 说明 |
|------|------|
| 自动保存 | 对话过程中自动创建检查点 |
| 状态恢复 | 重启后可以从任意检查点继续 |
| 历史浏览 | 查看完整的对话历史 |

## 使用场景

### 中断与恢复

```text
上午：让 AI 帮你写了一个函数 → 保存会话
下午：关闭电脑、外出
晚上：打开 Peak Code → 找到之前的会话 → 继续对话
```

### 多任务切换

```text
会话 A：正在开发新功能
会话 B：在修复另一个 Bug
会话 C：在审查代码
随时在不同会话之间切换
```

## 会话管理

| 操作 | 方式 |
|------|------|
| 创建新会话 | 点击"新建会话"按钮，选择代理和模型 |
| 切换会话 | 在侧边栏的会话列表中点击即可切换 |
| 删除会话 | 右键点击会话，选择"删除" |

> 会话数据存储在本地，不会上传到云端。
