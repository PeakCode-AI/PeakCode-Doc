# 实时流式输出

Peak Code 支持实时流式输出，让你即时看到 AI 代理的工作过程。

## 什么是流式输出？

传统的 AI 交互是"发送 → 等待 → 一次性返回"。流式输出则是 AI 边思考边输出，你能在第一时间看到结果。

```text
用户输入 → AI 思考中... → 逐步输出代码 → 实时显示在界面上
```

## 流式输出的好处

| 好处 | 说明 |
| --- | --- |
| 即时反馈 | 不用等到 AI 完全思考完毕，就能看到部分结果 |
| 更好的调试体验 | 看到 AI 的思考过程，更容易发现错误 |
| 减少等待焦虑 | 知道 AI 正在工作，而不是卡住了 |
| 工具调用可视化 | 实时看到 AI 调用了哪些工具、执行了什么命令 |

## 工具调用实时展示

当 AI 代理调用工具时（如读取文件、执行命令），你可以在界面上实时看到：

- 调用了什么工具
- 工具的输入参数
- 工具的执行结果

这让你完全了解 AI 在你的项目上做了什么操作。

::: info
流式输出默认开启，无需额外配置。
:::
