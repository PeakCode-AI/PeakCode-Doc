# 终端与编辑器

Peak Code 内置了终端和代码编辑器，让你无需离开应用即可完成所有操作。

## 内置终端

### 功能

- **命令执行** — 直接在应用中运行 shell 命令
- **AI 辅助** — AI 代理可以自动在终端中执行命令
- **多终端** — 同时打开多个终端标签
- **输出捕获** — 命令输出实时显示在界面上

### 使用方式

- 底部面板打开终端
- 支持 PowerShell、Bash、Zsh 等
- 命令历史和自动补全

## 代码编辑器

### 基于 Monaco Editor

Peak Code 的代码编辑器基于 [Monaco Editor](https://microsoft.github.io/monaco-editor/)（VS Code 使用的同款编辑器）：

- **语法高亮** — 支持主流编程语言
- **代码补全** — 智能代码提示
- **多文件编辑** — 同时打开多个文件
- **Diff 视图** — 直观对比文件变更

### 与 AI 协作

1. AI 生成代码后，你可以直接在编辑器中查看和修改
2. 修改后的文件会自动反映到 Git 变更中
3. 可以手动调整 AI 的输出，然后提交

## 终端 + 编辑器 + AI = 完整工作流

```
描述需求 → AI 编写代码 → 编辑器中查看 → 终端中测试 → Git 提交
```

整个流程在 Peak Code 一个应用中完成，无需在多个工具之间切换。
