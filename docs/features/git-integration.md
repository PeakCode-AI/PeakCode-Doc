# Git 集成

Peak Code 内置了完整的 Git 工作流，让你在与 AI 交互的同时管理版本控制。

## 功能概览

| 功能 | 说明 |
|------|------|
| 分支管理 | 创建、切换、删除分支 |
| 暂存与提交 | 暂存文件、创建提交 |
| 推送与拉取 | 推送到远程、拉取最新代码 |
| Diff 查看 | 查看文件变更内容 |
| 提交历史 | 浏览提交记录 |

## 为什么需要内置 Git？

AI 代理在帮你编写代码时，会产生大量文件变更。内置 Git 让你：

- **随时查看 AI 改了什么** — 在提交前审查所有变更
- **安全地回滚** — 如果 AI 的修改不满意，轻松回退
- **保持代码整洁** — 及时提交、合理分组变更
- **无需切换应用** — 在同一个窗口中完成编码和版本控制

## 使用方式

### 查看变更

AI 代理完成代码修改后，你可以直接在界面上查看：

- 哪些文件被修改了
- 每个文件的具体变更（diff）
- 新增、删除、修改的行数

### 提交代码

1. 选择要暂存的文件
2. 编写提交信息
3. 点击提交

### 分支管理

在界面中直接管理分支，无需打开终端。

## 与 AI 协作的最佳实践

1. **让 AI 在独立分支上工作** — 说"在这个分支上开发：feature/xxx"
2. **定期检查变更** — 使用 diff 功能审查 AI 的修改
3. **及时提交** — 保持提交历史清晰
4. **善用回滚** — 不满意的修改直接 revert
